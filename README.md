# FocusRoom

Hi 👋  
This is my first frontend project built using HTML, CSS, and JavaScript.

FocusRoom is a simple productivity web app that helps users stay focused using a Pomodoro timer and manage their daily tasks.

I built this project to improve my JavaScript fundamentals and understand how real web applications work.

---

## 🚀 Features

- ⏳ 25-minute Pomodoro focus timer  
- ▶ Start / Pause / Reset functionality  
- 📝 Add, complete, and delete tasks  
- 📊 Daily focus session tracking  
- 💾 Data saved using localStorage (no backend)  
- 🌙 Clean dark-mode UI  

---

## 🛠 Tech Stack

- HTML  
- CSS  
- JavaScript (Vanilla JS)  
- localStorage API  

No frameworks were used in this project.
